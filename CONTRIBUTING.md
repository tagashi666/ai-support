# Как помочь проекту

Спасибо за интерес к ai-support. Перед крупной доработкой сначала создайте
issue и опишите задачу: так мы не потратим время на несовместимые решения.

## Локальная разработка

```bash
cp .env.example .env
# Укажите тестовые BOT_TOKEN и PANEL_TOKEN, AI_MODE можно оставить off.
npm ci
npm run typecheck
npm test
npm run dev
```

Перед pull request должны проходить:

```bash
npm run typecheck
npm test
npm run build
npm run release:check
```

Не добавляйте в коммиты `.env`, базы SQLite, вложения, выгрузки Telegram и
реальные идентификаторы пользователей. Для тестов используйте явно вымышленные
данные. Новые миграции базы только дописываются в конец `MIGRATIONS`.

Сообщения коммитов делайте короткими и в повелительном наклонении. В pull
request опишите мотивацию, способ проверки и изменения конфигурации.
