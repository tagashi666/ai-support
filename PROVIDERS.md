# Выбор провайдера AI

Панель работает с любым OpenAI-совместимым эндпоинтом. Меняются три строки
в `.env`, код трогать не нужно:

```ini
AI_BASE_URL=...
AI_API_KEY=...
AI_MODEL=...
```

---

## Сначала посчитаем, сколько это вообще стоит

Один ответ поддержки — примерно 2000 токенов на вход (выдержки из базы знаний,
история диалога, карточка клиента) и 300 на выход. При 30 обращениях в день:

| | В месяц |
|---|---|
| Вход | ~1,8 млн токенов |
| Выход | ~270 тыс. токенов |
| **Стоимость на DeepSeek** | **меньше $1** |
| Стоимость на Moonshot | ~$1–2 |

То есть экономия на бесплатном тарифе здесь — это экономия доллара в месяц
ценой лимитов, простоев и чужих правил использования. Гнаться за бесплатным
стоит только на этапе обкатки, пока непонятно, взлетит ли вообще.

Второе, что важнее денег: **вы отправляете провайдеру переписку клиентов** —
платежи, суммы, скриншоты. У большинства бесплатных тарифов в условиях прямо
написано, что запросы могут использоваться для улучшения продукта. Для боевой
поддержки это отдельный аргумент против «бесплатно».

---

## Рекомендация по ситуациям

| Что важнее | Что брать |
|---|---|
| Данные клиентов не должны уходить наружу | своя модель на своём VPS |
| Работает из России, дёшево, надёжно | DeepSeek или Moonshot |
| Совсем бесплатно, для обкатки | Cloudflare Workers AI или OpenRouter |
| Уже есть аккаунт Cloudflare | Workers AI, 10 000 нейронов в сутки бесплатно |

---

## Своя модель на своём сервере

Самый честный вариант для сервиса, торгующего приватностью: переписка клиентов
не покидает вашу инфраструктуру, лимитов нет, геоблокировок нет.

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen3:8b
```

```ini
AI_BASE_URL=http://127.0.0.1:11434/v1
AI_API_KEY=ollama          # Ollama ключ не проверяет, но пустым оставлять нельзя
AI_MODEL=qwen3:8b
AI_TIMEOUT_MS=120000       # на CPU ответ идёт заметно дольше
```

Если контейнер и Ollama на одном хосте, вместо `127.0.0.1` подойдёт
`http://172.17.0.1:11434/v1` либо `network_mode: host` в compose.

На CPU ответ занимает десятки секунд — для режима `suggest` это нормально,
оператор всё равно читает предложку перед отправкой. Для `auto` нужен GPU
или модель поменьше.

## Cloudflare Workers AI

Бесплатно 10 000 нейронов в сутки, аккаунт Cloudflare у вас уже есть.
<cite index="25-1">Workers AI поддерживает OpenAI-совместимые эндпоинты для генерации текста, так что достаточно поменять базовый URL и название модели.</cite>

```ini
AI_BASE_URL=https://api.cloudflare.com/client/v4/accounts/АККАУНТ_ID/ai/v1
AI_API_KEY=ваш_cloudflare_api_token
AI_MODEL=@cf/meta/llama-3.1-8b-instruct
```

`АККАУНТ_ID` виден в панели Cloudflare или через `wrangler whoami`.
Токен создаётся с правом Workers AI. Из доступных моделей интереснее всего
`@cf/openai/gpt-oss-120b` и `@cf/qwen/qwen2.5-coder-32b-instruct`, полный
каталог — в документации Workers AI.

## OpenRouter

Один ключ на сотни моделей, среди них есть постоянно бесплатные с суффиксом
`:free`. <cite index="3-1">API совместим с форматом OpenAI, поэтому переписывать логику не нужно — достаточно поменять базовый URL, ключ и slug модели.</cite>

```ini
AI_BASE_URL=https://openrouter.ai/api/v1
AI_API_KEY=sk-or-v1-...
AI_MODEL=deepseek/deepseek-r1:free
```

Ограничение существенное: <cite index="17-1">на бесплатных маршрутах действует лимит 20 запросов в минуту и 50 в сутки, пока на балансе меньше $10; после пополнения на $10 суточный лимит поднимается до 1000.</cite> Пятидесяти ответов в сутки для поддержки может и хватить, но запаса нет.

## GitHub Models

Бесплатно по обычному GitHub-аккаунту, доступны в том числе модели OpenAI.

```ini
AI_BASE_URL=https://models.github.ai/inference
AI_API_KEY=ghp_ваш_personal_access_token
AI_MODEL=openai/gpt-4.1-mini
```

Два подвоха, из-за которых это годится только для проб: <cite index="12-1">ограничение на размер запроса — 8K токенов на вход и 4K на выход, что делает сервис пригодным скорее для прототипирования, а лимиты частоты привязаны к тарифу Copilot</cite>. Наш промпт с базой знаний и историей в 8K может не поместиться. Плюс <cite index="16-1">условия использования ограничивают GitHub Models экспериментами и прототипированием</cite> — для боевой поддержки это прямое нарушение.

## DeepSeek и Moonshot

Платные, но за копейки, работают из России без ухищрений.

```ini
# DeepSeek
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=sk-...
AI_MODEL=deepseek-chat
```

```ini
# Moonshot (Kimi) — стоит в шаблоне по умолчанию
AI_BASE_URL=https://api.moonshot.ai/v1
AI_API_KEY=sk-...
AI_MODEL=kimi-k2-0905-preview
```

## Groq — конфигурация по умолчанию

```ini
AI_BASE_URL=https://api.groq.com/openai/v1
AI_API_KEY=gsk_...
AI_MODEL=qwen/qwen3.8-27b
AI_MODEL_FALLBACK=openai/gpt-oss-120b
AI_VISION_MODELS=qwen/qwen3.8-27b
AI_REASONING_EFFORT=none
```

### Почему именно эта модель

`qwen/qwen3.8-27b` — официальный преемник снимаемой `Qwen3.6-27B` и единственная
оставшаяся в текущем каталоге Groq модель с изображениями. Она принимает текст
и до трёх картинок, поддерживает JSON и позволяет отключить рассуждения через
`reasoning_effort=none`. Модель preview, поэтому текст страхует production-
модель `openai/gpt-oss-120b`: у неё контекст 131K и более высокое качество, чем
у компактной 20B-версии.

Резерв учитывает возможности модели. Обычный текст при 429, снятии модели или
временном сбое уйдёт в GPT-OSS-120B. Сообщение с фото туда не уйдёт, поскольку
GPT-OSS текстовый: оно останется оператору, а не получит выдуманный ответ без
анализа изображения. При ручной смене моделей vision-разрешения задаются через
`AI_VISION_MODELS`.

### Голосовые бесплатно

В том же тарифе есть Whisper: 2000 запросов и 28 800 секунд аудио в сутки.
Голосовые сообщения — заметная часть обращений, а без расшифровки они для AI
невидимы, потому что текста в сообщении нет.

```ini
TRANSCRIBE_ENABLED=true
TRANSCRIBE_BASE_URL=https://api.groq.com/openai/v1
TRANSCRIBE_API_KEY=gsk_...
TRANSCRIBE_MODEL=whisper-large-v3-turbo
```

Расшифровка подставляется в текст сообщения, и диалог переигрывается — AI
видит его уже словами и делает предложку как по обычному тексту.

### Скриншоты

`AI_VISION=true` отправляет приложенные фото в Qwen3.8. Берутся до трёх
последних изображений из серии сообщений клиента. Каждое изображение у Groq
занимает 2048 входных токенов, поэтому стоимость и расход лимитов выше текста.

## Что уже учтено в коде

- **429 переживается**: клиент ждёт столько, сколько просит заголовок
  `Retry-After`, и повторяет до трёх раз. На бесплатных тарифах с лимитом в
  единицы запросов в минуту без этого предложки просто терялись бы.
- **Неверный ключ не ретраится** — 4xx кроме 429 падает сразу, с текстом ответа
  провайдера в логе.
- **Таймаут** настраивается через `AI_TIMEOUT_MS` — поднимите его для локальных
  моделей на CPU.
- **Ответ строго JSON** (`response_format: json_object`). Если модель формат не
  поддерживает, парсер всё равно вытащит JSON из markdown-обёртки, а совсем
  негодный ответ отбросит и запишет событие `ai_unparsed`.

## Проверка перед боем

```bash
docker compose run --rm ai-support node dist/selfcheck.js
```

Строка `AI провайдер` покажет, отвечает ли модель выбранным ключом.
